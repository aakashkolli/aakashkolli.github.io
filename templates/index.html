Projects

Adaptive ML Inference Server

Self-tuning inference server that adjusts batching, model precision, and routing in real time to hold a p99 latency SLO under changing traffic, without sacrificing GPU efficiency or accuracy. Model swaps are hitless, so in-flight requests are never dropped during a precision transition.

Built with Go, Python, ONNX Runtime, and gRPC. A PID controller with anti-windup drives adaptive batching, an EMA/CoV traffic analyzer selects between three DistilBERT precision variants, and a lock-free atomic.Value model reference keeps the hot path contention-free. Prometheus and Grafana expose PID state, batch efficiency, and cost metrics.

Go Python gRPC ONNX Runtime Prometheus Docker

Collaborative Document Editor

Real-time collaborative Markdown editor with live preview, threaded comments, and cursor presence. Comments anchor to text via CRDT relative positions, so they stay attached to the right content through concurrent edits, and late joiners replay full document state on connect.

Built with Next.js, Rust, and Yjs CRDTs. Uses an actor-per-room backend (one Tokio task per document) over a custom binary WebSocket protocol, with deterministic CRDT sync guaranteeing convergence for reconnecting and late-joining clients.

Rust Next.js Yjs WebSockets

Distributed DAG Task Scheduler

Crash-recoverable workflow orchestrator that resolves and executes dependency DAGs across a pull-based pool of distributed workers. Recovers automatically from worker or coordinator crashes with zero workflow-state loss on restart.

Built in Go with gRPC bidirectional streaming and BoltDB persistence. Uses atomic dependency resolution, heartbeat-based dead-worker detection, and execution tokens that reject stale results after a coordinator restart reconstructs and resumes in-flight workflows.

Go gRPC BoltDB Prometheus

Optimal Execution Algorithm Library

C++17 library that slices large equity orders into optimally timed child orders via TWAP, VWAP, and Implementation Shortfall, built on the Almgren-Chriss market impact model. The adaptive IS variant recalibrates its trajectory per slice with a constrained BVP solver (RK4 + Newton shooting), minimizing execution cost and risk against live market conditions.

Built with a lock-free order state machine, SPSC ring buffers, and a zero-allocation FIX 4.4 parser with O(1) tag dispatch. Includes a GBM-driven price-time-priority matching engine for simulation, pybind11 Python bindings, and a Polars post-trade analysis layer.

C++17 Python Eigen

NASDAQ ITCH Order Book Replay System

High-performance replay engine that reconstructs the full NASDAQ ITCH limit order book from raw binary feeds, with deterministic, bitwise-reproducible replay and queue-position fill modeling for realistic execution backtesting.

Built in C++ with zero-copy mmap parsing, a cache-aligned slab allocator, and Robin Hood hashing for order lookup. A fixed-range tick array and strict price-time priority processes 5M+ events/sec at sub-400ns p99 latency with zero heap allocations on the hot path.

C++17 pybind11 Google Benchmark

ML for European Options

Machine learning system for estimating implied volatility and pricing European SPX options using historical market data. Compares tree-based models and neural networks against traditional Black-Scholes methods to evaluate tradeoffs between predictive accuracy and computational efficiency.

Built in Python using XGBoost, Random Forests, and neural networks trained on historical options data. Includes a full preprocessing and evaluation pipeline, volatility surface visualization, Black-Scholes benchmarking, and a Streamlit interface for interactive model exploration.

Python scikit-learn Black-Scholes Streamlit
